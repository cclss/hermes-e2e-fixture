# NEON BLITZ — VS A.I. Tetris

인공지능과 1:1로 맞붙는 **네온 아케이드 대전 테트리스**. 순수 HTML · 바닐라 JS ·
CSS로 만들었고, 빌드 도구·외부 런타임 의존성이 없다. 이펙트와 사운드까지 모두
브라우저에서 실시간 합성한다(이미지/오디오 에셋 0개).

## 실행

정적 파일이라 별도 빌드가 필요 없다. 저장소 루트에서 정적 서버를 띄우고 열면 된다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

> ES 모듈을 쓰므로 `file://` 직접 열기 대신 로컬 서버로 띄워야 한다.

## 조작법

| 동작 | 키 |
|------|-----|
| 좌 / 우 이동 | `←` `→` (또는 `A` `D`) |
| 소프트 드롭 | `↓` (또는 `S`) |
| 하드 드롭 | `Space` |
| 시계 방향 회전 | `↑` (또는 `X`) |
| 반시계 방향 회전 | `Z` (또는 `Ctrl`) |
| 홀드 | `C` (또는 `Shift`) |
| 일시정지 / 재개 | `P` (또는 `Esc`) |
| 시작 / 리매치 | `Enter` (또는 `R`) |
| 소리 켜기 / 끄기 | `M` (또는 우상단 `SFX` 버튼) |

핸들링은 DAS `110ms` · ARR `16ms` · 소프트드롭 `24ms`로 날카롭게 맞춰 두었다.

## 대전 규칙

1:1 가비지(패널티 라인) 대전이다. 먼저 **탑아웃(블록이 천장에 막힘)** 당하는 쪽이 패배.

### 공격 — 라인을 지워 상대를 압박한다
지운 줄 수·스핀·연쇄에 따라 상대에게 보낼 가비지 라인이 정해진다.

| 클리어 | 전송 라인 |
|--------|-----------|
| 싱글 / 더블 / 트리플 / 테트리스 | 0 / 1 / 2 / 4 |
| T-스핀 싱글 · 더블 · 트리플 | 2 / 4 / 6 |
| T-스핀 미니 싱글 · 더블 | 1 / 2 |
| Back-to-Back(난이도 클리어 연쇄) | **+1** |
| 콤보(연속 클리어) | 누적될수록 +1 ~ +5 |
| 퍼펙트 클리어 | **+10** |

### 콤보 — 길수록 뜨겁다
연속으로 라인을 지우면 콤보가 쌓이고, **상승 효과음의 음정이 단계마다 올라가며**
화면 콜아웃과 함께 압박이 커진다. 끊기지 않게 몰아치는 게 핵심.

### 예고 → 반격 (공정성)
전송된 가비지는 곧장 들어오지 않는다. 약 `0.9초` 동안 상대 보드 가장자리에 **예고
바**로 충전되고, 충전이 끝난 라인만 **상대가 라인을 못 지운 드롭 시점에** 삽입된다.
그 사이 내가 라인을 지우면 들어올 가비지를 **상쇄(counter)** 할 수 있다 — 반격 창은
항상 열려 있다.

### 도발 (티배깅)
상대를 **KO 직전까지 몰았을 때**, 소프트드롭 키를 빠르게 연타하면 도발이 성립한다.
약 올리는 콜아웃·이펙트·전용 효과음과 함께 **소량의 추가 압박(1줄, 예고)** 을 준다.
AI도 당하고만 있지 않고 가끔 되받아친다. (남발은 쿨다운으로 막혀 있다.)

## 난이도

시작 화면에서 상대 AI를 고른다.

- **EASY — WARM-UP BOT**: 느리고 실수가 잦다. 몸풀기.
- **NORMAL — FAIR FIGHT**: 공정한 한 판.
- **HARD — NO MERCY**: 빠르고, 거의 실수하지 않으며, 테트리스 우물로 공격적으로 압박.

## 사운드

이동·회전·락·하드드롭·라인클리어·콤보 상승음·가비지 수신·도발·KO 효과음과 가벼운
BGM을 모두 Web Audio로 실시간 합성한다. `M` 키 또는 우상단 `SFX` 버튼으로 즉시 음소거
할 수 있고, 설정은 브라우저에 기억된다.

## 구조

게임 규칙(엔진)·렌더·입력·AI·대전·흐름·오디오를 레이어로 분리했다. 엔진은 헤드리스
순수 로직이고, 각 상위 레이어는 엔진 **이벤트를 구독**해 화면·소리·연출만 담당한다.

```
src/engine/   코어 테트리스 규칙 (DOM/오디오 비의존, 순수 로직)
src/render/   캔버스 렌더러 + 이펙트(파티클·플래시·셰이크)
src/input/    키보드 컨트롤러 (DAS/ARR)
src/ai/       휴리스틱 대전 봇
src/versus/   가비지·콤보 공격·티배깅
src/game/     세션 루프 + 화면/게임 흐름
src/audio/    Web Audio 합성 SFX·BGM (이벤트 구독 레이어)
```

테스트:

```bash
npm test   # 엔진 · AI · 대전 로직 검증 (DOM 없이)
```

설계 결정 기록은 [`docs/recording.md`](docs/recording.md) 참고.
